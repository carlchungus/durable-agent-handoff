# v0.4.0

v0.4.0 makes runtime work independently observable and controllable without moving process lifecycle into conversational Session state.

## Highlights

- Shared supervisor-private `secureledger` storage for Sessions and Activities, retaining the existing Session event/snapshot format.
- `handoff activity list|read|follow|stop`, durable output identities and byte cursors, exact process birth tokens, supervisor ownership, and generation-fenced controls.
- Deterministic crash recovery that adopts a surviving worker, resumes output at an exact cursor, rejects stale controls, and stops only the named process execution.
- Agent turns and delegated child agents backed by Activities while Sessions continue to own conversation identity and inbox delivery.
- Observable role ladders across Claude, Codex, Pi, and OhMyPi. Provider fallback retains one logical Activity and can never widen the job sandbox.
- Guarded PR finalization remains opt-in and requires an independent pass, diff budgets, an unchanged verified head, and every explicitly named CI gate.

## Compatibility and upgrade

The Activity schema is new and additive. Existing workflow, Session, team, and preference state remains readable. Existing live attempts created by older prerelease builds may lack a supervisor ID; the first v0.4 supervisor reconciliation adopts them once and writes the new owner identity.

Keep `HANDOFF_HOME` outside every worker-writable worktree. Stop older `handoff serve` processes before replacing the binary, then restart the service so the new supervisor can reconcile durable state.
